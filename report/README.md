# Report

This folder is reserved for the final written report. The report should draw
tables and figures from `results/` so claims remain tied to reproducible
experiment artifacts.

Suggested structure:

1. Problem and motivation.
2. Dataset and preprocessing.
3. Model and uncertainty methods.
4. In-distribution results.
5. Selective deferral.
6. Distribution-shift results.
7. Limitations and reproducibility.
